# kichijitsu ブランドアセット

コンセプト: **枡の週**。7つの枡（カレンダーのセル）＝1週間。日々は薄墨で平等に並び、
選ばれた日だけ朱の枡が**手で押印されたように少し傾いて (-8°)** 載る。
日々は平等で、選ぶ行為が吉日を作る——「思い立ったが吉日」。

## アセット

| ファイル        | 用途                                                                          |
| --------------- | ----------------------------------------------------------------------------- |
| `mark-week.svg` | 横長マーク。ヘッダー・README・OG 画像の素材                                   |
| `tile.svg`      | アプリアイコン (48px〜)。月グリッド 3x2 版                                    |
| `favicon.svg`   | ファビコン。16px でも読める 2x2 簡約版                                        |
| `wordmark.svg`  | ワードマーク（確定版 2026-07-19）。**手編集禁止**、再生成は `gen-wordmark.js` |

PWA アイコン (`apps/web/public/icons/*.png`) は `tile.svg` からの生成物。
**手編集禁止**、再生成は `gen-pwa-icons.js`（`pnpm --filter web gen:icons` でも可）。

### ワードマーク

- Inter SemiBold（SIL OFL 1.1, https://rsms.me/inter/）を**アウトライン化**した
  固定ジオメトリ。フォント・OS に依存しない
- **i の点3つ = 正立した墨の枡**（`currentColor` — ダークテーマで自動反転）、
  **j の点 = -8° 傾いた朱の枡**（stem 幅の 1.35 倍、墨枡は 1.08 倍）
- 調整したいときは `gen-wordmark.js` のパラメータ（枡サイズ比・傾き・字間）を
  変えて再生成する（要 opentype.js + Inter-SemiBold.otf。手順はスクリプト冒頭）
- 位置を目分量の em で調整する文字組み実装は廃止（フォント差でズレるため）

### 朱の値の変更（2026-07-26、WCAG AA 適合）

旧値は 朱 `#D7402E` / `#E8543F`。この朱は

1. **文字を載せる地**（今日バッジ・主ボタン。暗いほどコントラストが稼げる）
2. **文字・線そのもの**（予定リンク・フォーカスリング。暗い地の上では明るいほど稼げる）

という真逆の要求を1色で兼ねており、旧値では「朱の枡に生成りの数字」がライト 4.21:1 /
ダーク 3.23:1 と AA (4.5:1) に届いていなかった。

用途ごとに朱を2色へ割るのではなく（「アクセントは朱ひとつ」が壊れるため）、
**朱を地から離す向きへ明度だけ動かして1色を維持**した。上に載る文字を生成り
（＝ダークでは暗い側）にしたことで、両モードとも「朱を地から離す」という同じ一方向で
地・文字の両方が同時に良くなるため、1色で足りる。

- 色相・彩度は旧値のまま（H 6.4°→6.5° / S 67.9%→67.8%、H 7.46°→7.45° / S 78.6%→78.5%）。
  変えたのは明度だけなので、淡い朱の派生色は同じ色みのまま揃っている
- 実測: 今日バッジ ライト 5.14:1 / ダーク 5.52:1。文字として最も不利な地の上でも 4.66 / 4.70
- 傾き -8° と「アクセントはひとつ」の原則は不変

追随が必要なもの（値を変えたら**必ず同時に**）:
`brand/*.svg`・`gen-wordmark.js` / `apps/web/public/{favicon,wordmark}.svg` /
PWA アイコン PNG（`gen-pwa-icons.js` で再生成）/ `apps/web/{index,privacy,terms}.html` /
`apps/web/src/theme.css` の `--c-accent` と `--c-accent-rgb` / `apps/site/**`。

## 枡オーナメント（UI 全体への展開）

枡ひとつ＝「一日」「一項目」を最小単位の記号として UI 全体で使う。

- **薄墨の正立した枡** = ふつうの項目（箇条書きの点、メニュー項目、未選択）
- **枠だけの空枡** = 未完了（チェックボックスの unchecked）、および**オフライン/未接続**
  （ツールバーの空枡 +「オフライン」= サーバーに届かない状態。表示はローカルレプリカで継続）
- **朱で -8° 傾いた枡** = 選ばれた・済んだ・今日（メニュー現在地、完了チェック、今日の日付バッジ）
- 傾きと朱は必ずセット。「人の手が判を押した」の意味。薄墨の枡は常に正立
- サイズは文字に対して 0.48〜0.52em
- 朱の枡は1つのまとまりにつき基本1個（完了リスト等の例外時は他の朱要素を置かない）
- アニメーションは「置く・押す」の2語彙のみ（インジケーターと共通）。回転・バウンド追加禁止
- 適用先の例: 箇条書き・設定メニュー・チェックボックス（完了=押印）・週ヘッダーの今日バッジ
- **機能色の例外**（ユーザー決定 2026-07-19）: カレンダー選択のようにデータ自体が色を持つ
  文脈では、選択済み枡の塗りにその**データの色**（カレンダー色）を使ってよい。
  傾き -8° は維持する（押印の意味は傾きが担い、朱は「特に選ばれた一つ」の色として温存）

## ルール

- ワードマークの j の点（tittle）は**常に朱の枡**（ユーザー決定 2026-07-19。
  マーク併用時も朱のまま——ロゴ領域内はこの2つで1つのアクセントとみなす）
- j の枡は i の点と**高さ中央揃え**にする（i の tittle の中心と枡の中心を一致させる）
- ロゴ領域の外では、アクセントの朱はひとまとまりにつき1つの原則を守る
- 朱の枡の傾きは常に **-8°**。傾きが変わると別人になる
- モーション＝**枡インジケーター**（同期中・展開中などのローディング表示。ロゴがそのまま動く）:
  - 1周 1820ms、枡の登場ずれ 130ms、イージング cubic-bezier(.2,.7,.3,1)
  - 通常の枡は scale .55→1 で静かに置かれる。朱の枡のみ押印オーバーシュート
    (scale 1.45→1→1.06→1、常に rotate(-8deg))
  - `prefers-reduced-motion: reduce` では静止した完成形マークを表示
  - 停止時は現在の周回を完走してからフェードアウト（ぶつ切り禁止）
  - 実装は `apps/web/src/components/MasuIndicator.tsx`
