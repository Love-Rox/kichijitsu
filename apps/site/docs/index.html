ドキュメント

kichijitsu の使い方と、自分で運用するときの手引き。 読む人によって必要なページが違うので、「使う人向け」と「運用する人向け」に分けてある。

目次

  1. 使う人向け
  2. 運用する人向け

使う人向け

kichijitsu で予定を扱う人へ。上から順に読めば、ひととおり使えるようになる。

  • はじめかた /docs/start/ Google アカウントでログインし、複数アカウントを束ね、画面の各部を把握するまで。
  • 予定の扱い /docs/calendar/ 表示の切り替え、予定の作成・編集・複製、RSVP 返信、ゲスト (参加者) の確認と追加・削除、不在、勤務場所、キーボードショートカット。
  • GitHub 連携と実績記録 /docs/work/ issue・PR を作業キューに載せ、かけた時間を記録してグループごとに集計する。
  • カレンダーブロック /docs/blocking/ 別のカレンダーへ予定を自動でミラーして、多重予約を防ぐ設定。
  • デスクトップ版と PWA /docs/apps/ Tauri 製アプリと PWA の入れかた・更新のされかた、デスクトップ版だけの予定のリマインダー通知、更新されないときのキャッシュ削除と再同期。
  • データの扱い /docs/data/ 予定・認可情報・UI 設定が、それぞれどこに保存されるか。
  • MCP 接続ガイド /mcp/ Claude などのエージェントに予定を読み書きさせるための接続手順と、使えるツール一覧。

運用する人向け

自分の Cloudflare アカウントに kichijitsu を立てて、自分で運用する人へ。

  • セルフホスト手順 /self-hosting/ リポジトリの準備から Google OAuth クライアントの作成、デプロイ、セキュリティ設定まで。
  • 運営者情報と規約の差し替え /docs/operator/ あなたのインスタンスの規約・プライバシーポリシーに、あなたの運営者情報を出す。
